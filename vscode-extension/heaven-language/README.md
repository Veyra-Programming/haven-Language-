# 🕊️ Heaven (Haven) Programming Language for Visual Studio Code

Official VS Code extension for the **Heaven (Haven) Programming Language** (v2.0), providing natural-English syntax highlighting, AST diagnostics, hover tooltips, snippets, and ODCS digital continuity integration.

![Heaven Language](assets/logo.png)

## Features

- **Natural-English Syntax Highlighting**: Full TextMate grammar for `set ... to`, `remember ... as`, `whenever ... :`, `give back`, `for each ... in`, `repeat N times`, and comparisons (`is equal to`, `is at least`).
- **Real-Time Diagnostics**: Instant linter notifications and squiggly error underlines in the editor and Problems panel.
- **Rich Hover Documentation**: Instant tooltips explaining keywords, durable records, and ODCS primitives (`ContinuityLedger`, `ZeroIntentLoss`, `PNCounter`, `canonical_json`, `seal_hash`).
- **Snippets Catalog**: One-click snippets for HTTP gateways, durable records, CRDT meshes, and checkpoints.
- **Transpile & Inspect**: Side-by-side view of compiled Python target code with one keystroke.
- **One-Click Gateway Runner**: Run the official ODCS continuity backend server directly from the editor.

## Commands
- `Heaven: Run Active File` (`heaven.run`)
- `Heaven: Lint & Validate Syntax` (`heaven.lint`)
- `Heaven: Transpile to Python Target` (`heaven.compile`)
- `Heaven: Start ODCS Continuity Gateway` (`heaven.startServer`)
- `Heaven: Launch Interactive REPL` (`heaven.repl`)
- `Heaven: Show Actions Menu` (`heaven.showMenu`)
